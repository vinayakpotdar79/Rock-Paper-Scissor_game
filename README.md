# Rock-Paper-Scissors Game 🎮

A fun and interactive browser-based **Rock-Paper-Scissors** game built using HTML, CSS, and JavaScript. The game allows players to compete against the computer while tracking scores and determining the overall winner after a set number of rounds.

---

## Features
- **Dynamic Gameplay**: Play against the computer with randomized moves.
- **Interactive UI**: Real-time updates to images and animations for each move.
- **Score Tracking**: Displays the player's and computer's scores throughout the game.
- **Round Configuration**: Players can set the number of rounds before starting the game.
- **Responsive Design**: Visually appealing interface with animations.

---

## Technologies Used
- **HTML**: Structure and layout of the game.
- **CSS**: Styling and animations.
- **JavaScript**: Game logic and interactivity.

---

## How to Play
1. **Set Rounds**: Enter the number of rounds you want to play and click the **OK** button.
2. **Make a Move**: Choose between **Rock**, **Paper**, or **Scissors** by clicking the respective button.
3. **Game Flow**:
   - The computer will make a random choice.
   - Both choices will display with animations.
   - The winner of the round will be updated in the score section.
4. **View Results**:
   - Once all rounds are complete, the game will display the final result: Win, Lose, or Tie.
   - You can start a new game by clicking the **New Game** button.
